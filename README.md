# 驾考手册

一个开箱即用的中文驾考练习网页雏形，可通过 Docker Compose 部署。当前版本为纯前端静态应用，无需数据库或外部 API。

## 功能

- 响应式学习首页与每日练习进度
- 科目一、科目四及交通标志专项练习
- 答题即时反馈、解析、错题回顾和题目收藏
- 今日答题量、累计答题、正确率、连续练习天数
- 使用浏览器 `localStorage` 保存练习数据
- 针对手机窄屏优化的单列题目卡片、触控尺寸、底部答题面板与安全区适配

> 题目目前为少量演示数据。页面提供 [题吧公开题库](https://tiba.jsyks.com/) 来源入口，但没有抓取或同步该站题库。来源站首页版权信息说明其试题获得合法使用授权；这不代表本项目获得复制、抓取或再发布许可。若需真实题库接入，请使用获得授权的 API 或你有权使用的题库文件。学习数据只存储在当前浏览器，不会同步至其他设备。

## 使用 Docker Compose 启动

要求安装 Docker Engine/Desktop 与 Docker Compose v2。在项目目录执行：

```sh
docker compose up -d --build
```

浏览器打开：<http://localhost:12123>

查看服务状态和健康检查：

```sh
docker compose ps
```

查看日志：

```sh
docker compose logs -f
```

停止服务：

```sh
docker compose down
```

### 修改访问端口

Compose 默认把主机端口 `12123` 映射到容器端口 `12123`。如需修改，请编辑 `docker-compose.yml` 中的端口映射；容器内部 Nginx 固定监听 `12123`。

## 直接预览

也可以直接用现代浏览器打开 `index.html`。练习记录保存在当前浏览器的本地存储中。

## 项目文件

- `index.html`：单页应用、样式、示例题库和交互逻辑
- `Dockerfile`：构建 Nginx 静态站点容器
- `nginx.conf`：静态站点与健康检查路径配置
- `docker-compose.yml`：Compose 服务编排

## 题库来源与接入

目前题库是内置在 `index.html` 中的少量示例题。题吧主页提供科目一、科目四的公开题库入口，但项目没有将其内容抓取或复制进来。需要从题吧或其他来源加载真实题目时，请先确认使用授权，并提供该来源支持的 API 或授权数据文件；之后可将前端题目数组替换为受许可的数据源。
